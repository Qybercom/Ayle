Ayle / Embedded

Four canonical declarative examples

All four variants use the bootstrap/declarative API. The code shown under every preview is the exact configuration used to create that player.

Minimal video

Minimal UI + video media mode.

minimal-video
Declarative embed
<script
	type="application/json"
	data-ayle="embedded-minimal-video"
	data-ayle-settings="localStorage">
{
	"File": "example.mkv",
	"Driver": {
		"Type": "mse"
	},
	"Player": {
		"AutoPlay": false,
		"AutoFocus": true,
		"MediaMode": "video",
		"UIMode": "minimal",
		"Volume": 0.8,
		"Muted": false,
		"Start": 0,
		"UI": {
			"Header": [],
			"Track": ["title", "chapter"],
			"Channel": ["name", "profile"],
			"Overlay": ["track:compact"],
			"Toolbar": {
				"Layout": "inline",
				"Items": ["play", "timeline", "time", "volume"]
			}
		}
	},
	"HTTP": {
		"MetadataURL": "../../server/metadata.php?file={file}",
		"TrackURL": "../../server/track.php?file={file}&type={kind}&track={track}&start={time}",
		"Stream": {
			"SkipInit": true
		}
	}
}
</script>
